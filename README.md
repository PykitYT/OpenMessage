# Установка/настройка
установка:
1. Создайте папку
2. скачайте файл в папку
3. скопируйте путь к папке
4. нажмите win r
5. напишите cmd и нажмите enter
6. введите cd путь/к/папке
7. теперь вы можетк перейти к настройке

настройка:
1. откройте cmd и напишите cd путь/к/папке (если закрыт)
2. если у вас есть папка "plugins" с папкой где main.py:
   1. напишите:
```
python main.py --reset
```

3. установите систему через:
```
python main.py --update
```
4. Готово! можете создавать плагины!
# Как создать плагин
если вы хотите при запуске:
```

```
если вы хотите при команде:
1. Своя команда
```

  print("Команда запущена!") #Замените на нужный скрипт
```
2. Тест
```
#msg
```
